# Genshin Flood Bot

Бот для анкет и обращений с отдельной админ-панелью.

## Запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение:
   `python -m venv .venv`
3. Активировать его.
4. Установить зависимости:
   `pip install -r requirements.txt`
5. В `.env` проверить токен, ADMIN_IDS и GROUP_LINK.
6. Запустить:
   `python main.py`

## Котики

Положи JPG/PNG/WEBP в папку `cats/`.

## Важно

Токен уже записан в локальный `.env` этого архива по просьбе владельца. Не публикуй архив в GitHub и не отправляй его посторонним.
